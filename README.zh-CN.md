# GIF 区域录制小工具（Windows）

按快捷键 → 框选屏幕区域 → 确认并倒计时 → 自动开始录制 → 裁剪时间段 → 导出为 GIF。

## 直接用（推荐）

**GifRecorder.exe**（30KB，单文件，Win10/11 双击即用，自带图标）：

1. 双击运行，出现主界面（关闭窗口会最小化到托盘，右键托盘图标可退出）
2. 点「框选并录制」或按 **Ctrl+Shift+R**，拖拽框选录制区域
3. 确认对话框：可**重新框选**，点「开始录制」（支持 3 秒 / 5 秒倒计时，在主界面设置）
4. 右上角红色指示器：点「停止」/ 按 **Esc** / 再按快捷键 → 进入裁剪界面
5. 裁剪界面：拖动进度条预览每一帧，设置**开始 / 结束时间**，可试看裁剪段，点「导出 GIF」
6. GIF 自动保存（可在主界面改保存目录），并自动打开文件夹定位文件

主界面可调：帧率（5–20 FPS）、倒计时、保存目录，设置自动记住。

> 快捷键被占用时第一次运行会弹窗提示。

## 脚本版（v1，Python，想自己改功能的话）

需要 Python 3.9+（[官网下载](https://www.python.org/downloads/)，安装时勾选 "Add python.exe to PATH"）。

```cmd
cd gif-recorder
pip install -r requirements.txt
```

## 使用

```cmd
python gif_recorder.py
```

1. 按 **Ctrl+Shift+R**，屏幕变暗，鼠标拖拽框选要录制的区域
2. 松开鼠标 → 立即开始录制，右上角出现红色指示器（带计时）
3. 停止录制三选一：
   - 再按一次 **Ctrl+Shift+R**
   - 按 **Esc**
   - 点击指示器上的"停止并导出 GIF"按钮
4. GIF 自动保存到「图片 / GIF 录制」文件夹，并自动打开该文件夹

框选时按 **Esc** 可取消。

## 自定义

直接改 `gif_recorder.py` 顶部的配置区：

| 配置 | 说明 | 默认值 |
|---|---|---|
| `HOTKEY_TOGGLE` | 开始/停止的全局快捷键 | `ctrl+shift+r` |
| `FPS` | 帧率，越大越流畅、文件也越大 | `10` |
| `MAX_SECONDS` | 单次最长录制秒数 | `60` |
| `OUTPUT_DIR` | GIF 保存目录 | `图片/GIF 录制` |

## 打包成 exe（可选，不想装 Python 的话）

```cmd
pip install pyinstaller
pyinstaller --noconsole --onefile --name GIF录制 gif_recorder.py
```

生成的 `dist/GIF录制.exe` 双击即用。注意：

- 部分杀毒软件会对 PyInstaller 打包的程序误报，属正常现象
- 快捷键无反应时，右键 exe → 以管理员身份运行

## 常见问题

- **看不到"框选"界面？** 目前只支持主显示器，多屏用户请在主屏上操作。
- **录出来颜色不对 / 闪烁？** 把问题描述发给开发者即可，导出逻辑已做过抽样调色板优化。
- **想录得更清晰？** 调高 `FPS`，或框选更小的区域（GIF 文件会小很多）。
