# GIF 領域録画ツール（Windows）

ホットキー → 画面の領域を選択 → 確認＆カウントダウン → 自動で録画開始 → 時間範囲をトリミング → GIF として出力。

## すぐに使う（おすすめ）

**GifRecorder.exe**（30KB、単一ファイル、Win10/11 でダブルクリックするだけ、アイコン付き）：

1. ダブルクリックで起動、メイン画面が表示される（ウィンドウを閉じるとタスクトレイに最小化、トレイアイコンを右クリックで終了）
2. 「範囲選択して録画」をクリック、または **Ctrl+Shift+R** を押して、ドラッグで録画範囲を選択
3. 確認ダイアログ：**選択し直し**可能、「録画開始」をクリック（3秒 / 5秒 のカウントダウン対応、メイン画面で設定）
4. 右上の赤いインジケーター：「停止」をクリック / **Esc** を押す / もう一度ホットキー → トリミング画面へ
5. トリミング画面：シークバーをドラッグして各フレームをプレビュー、**開始 / 終了時刻**を設定、トリミング範囲を試し見して「GIF を出力」
6. GIF は自動保存（保存先はメイン画面で変更可）、保存後にフォルダを自動で開く

メイン画面で調整可能：フレームレート（5–20 FPS）、カウントダウン、保存先。設定は自動で記憶されます。

> ホットキーが他と競合している場合、初回起動時にポップアップで通知します。

## スクリプト版（v1、Python、カスタマイズしたい人向け）

Python 3.9+ が必要（[公式サイト](https://www.python.org/downloads/)からダウンロード、インストール時に "Add python.exe to PATH" にチェック）。

```cmd
cd gif-recorder
pip install -r requirements.txt
```

## 使い方

```cmd
python gif_recorder.py
```

1. **Ctrl+Shift+R** を押すと画面が暗くなり、ドラッグで録画したい範囲を選択
2. マウスを離す → すぐに録画開始、右上に赤いインジケーター（タイマー付き）が表示される
3. 録画の停止は3通り：
   - もう一度 **Ctrl+Shift+R** を押す
   - **Esc** を押す
   - インジケーターの「停止してGIFを出力」ボタンをクリック
4. GIF は「ピクチャ」フォルダ内に自動保存され、そのフォルダが自動で開きます

範囲選択中に **Esc** を押すとキャンセルできます。

## カスタマイズ

`gif_recorder.py` 冒頭の設定エリアを直接編集してください：

| 設定 | 説明 | デフォルト |
|---|---|---|
| `HOTKEY_TOGGLE` | 開始/停止のグローバルホットキー | `ctrl+shift+r` |
| `FPS` | フレームレート。高いほど滑らか、ファイルも大きくなる | `10` |
| `MAX_SECONDS` | 1回の最大録画秒数 | `60` |
| `OUTPUT_DIR` | GIF の保存先 | `Pictures/GIF 录制` |

## exe化（任意、Python を入れたくない場合）

```cmd
pip install pyinstaller
pyinstaller --noconsole --onefile --name GIF録画 gif_recorder.py
```

生成された `dist/GIF録画.exe` はダブルクリックですぐ使えます。注意：

- 一部のアンチウイルスソフトが PyInstaller 製のプログラムを誤検知することがありますが、正常な現象です
- ホットキーが反応しない場合は、exe を右クリック → 管理者として実行してください

## よくある質問

- **「範囲選択」画面が出ない？** 現在はメインディスプレイのみ対応です。マルチディスプレイの方はメイン画面で操作してください。
- **色がおかしい / チラつく？** 問題の内容を開発者までお知らせください。出力ロジックはサンプリングパレットで最適化済みです。
- **もっと綺麗に録りたい？** `FPS` を上げるか、選択範囲を小さくしてください（GIF ファイルもかなり小さくなります）。
